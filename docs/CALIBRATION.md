# Match engine calibration

Each tier plays 40 fresh 20-club seasons (seeds 5000-5039; tuning used
other seeds) and is compared with typical top-flight European league
values. The tactic rows show season points gained per step of each
slider; a large value would mean one style simply wins.

Regenerate with `scripts/calibration-report.sh`.
